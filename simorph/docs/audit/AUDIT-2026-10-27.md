# SIMORPH — Audit technique intégral du workspace (2026-10-27)

Périmètre : le workspace `simorph/` tel que livré au commit `7140ede`
(319 fichiers suivis, 39 456 lignes de Rust, 443 lignes de Python,
32 paquets Cargo, 270 tests).

Méthode : trois audits indépendants (moteurs ; noyau d'exécution et
sécurité ; services, applications et plugins), conduits par des agents qui
n'avaient pas écrit le code concerné et à qui l'on a demandé de ne rien tenir
pour acquis ; sondes exécutées (programmes de test hors dépôt) ; couverture
mesurée avec `cargo llvm-cov` ; revue statique complémentaire de la sécurité ;
vérification des 28 dépôts open source demandés. Les corrections apportées
depuis sont listées au §9 et dans `../STATUS.md`.

**Règle de lecture.** Un test qui passe, une couverture élevée ou un module
qui porte le nom d'une capacité ne prouvent pas cette capacité. Le cas du
plugin physique l'illustre : 99,1 % de couverture et 14 tests verts, mais un
couplage thermique physiquement inversé (§4.3).

## 2. Tests et couverture

* 270 tests, tous verts au départ ; un test intermittent
  (`subprocess::tests::python_round_trip…`) révélait une vraie course dans le
  plafond de sortie.
* Couverture de lignes mesurée : **88,1 %** (fonctions 86,8 %), détail par
  crate dans `coverage-2026-10-27.md`. Zones les moins couvertes : pont Python
  (73 %), CLI (75 %), runtime de campagne (77 %), fabrique de simulateurs (78 %).
* Tests jugés **tautologiques** : comparaison de deux listes d'actions écrites
  à la main ; cas de référence « période orbitale » comparant la formule de
  Kepler à elle-même ; constante d'hypervolume ZDT1 fausse (0,7767 au lieu de
  ≈ 0,8767), ce qui abaissait le seuil effectif du test ; tests de
  classification et de protection qui ne vérifiaient que les règles du module.

### 4.2 Fonctionnalités simulées, factices ou surévaluées
* « Gain informatif » : constantes et heuristiques par type d'expérience, non
  information-théoriques.
* Raisonneur et configuration LLM : jamais appelés.
* Fabrique de simulateurs : réutilise un composant ou **transcrit** des
  équations fournies ; ne génère pas de physique nouvelle (honnêtement signalé
  RR-1, mais le terme « génération » surévaluait).
* Contradictions : jamais marquées résolues ; détection limitée à des entrées
  identiques.
* Recherche de contre-exemples : jamais planifiée.

### 4.3 Plugins
Formules vérifiées correctes : Colebrook (f = 0,0185139 à Re = 10⁵,
ε/D = 10⁻⁴), poutre, M/M/1, logistique, éolienne, constantes orbitales, J2,
batterie. Défaut : couplage thermique du nanosatellite (S8).
